# 쌓이는 요령 (에이전트가 작업하며 고치는 기록)

다음 작품에도 쓸 수 있는 요령만 적는다. 작품 하나에만 해당하는 사실은 적지 않는다.

적는 법:
- **주제별 단락 안에** 덧붙인다(플랫폼, 출판사, 납품 자료, 도구). 작품 이름으로 단락을 만들지 않는다.
- 이미 적힌 내용과 같으면 적지 않는다. 같은 일을 다시 겪었으면 그 줄 끝의 확인 횟수만 고친다(예: `확인 3회`).
- 적힌 내용이 틀렸거나 바뀌었으면 그 줄을 고친다. 덧붙여서 서로 다른 말이 두 줄 남게 하지 않는다.
- 줄 앞에 날짜(처음 적은 날)를 둔다.

## 플랫폼

### 리디 (ridibooks.com)
- 2026-09-29: 작품 주소는 검색 엔진(WebSearch)에서 제목+저자로 찾는 것이 빠르다. 형식 `https://ridibooks.com/books/<번호>`.
- 2026-09-29: 작품 페이지는 화면 없는 브라우저를 막는다(접속 확인 화면). render 명령은 막히면 화면 있는 Edge 로 다시 열기 때문에 그대로 쓰면 된다.
- 2026-09-29: 권별 공개일은 권 목록의 "등록일 YYYY.MM.DD". 페이지 위쪽의 "YYYY.MM.DD 업데이트", "YYYY.MM.DD 출간"(출간 정보)은 작품 전체 값이라 권별 공개일이 아니다. 등록일이 출간 정보보다 이를 수 있다(구판 등록 후 재출간). 확인 4회.
- 2026-09-29: 권 목록에는 대여가만 보이고, 소장가는 위쪽 "소장 / 단권 / 판매가"에 있다.
- 2026-09-29: 출판사 표기는 "KOCN 출판"처럼 이름 뒤에 '출판'이 붙어 나온다. '출판'은 표시 문구다.
- 2026-09-29: 페이지 아래쪽에 "성인 인증 안내" 문구가 모든 작품에 들어 있다. 등급 근거가 아니다. 리디 화면에는 명시적 이용등급 표기가 없는 경우가 많다.
- 2026-09-29: 분류가 "극화"와 "코믹"처럼 둘이 함께 나올 수 있다. 화면 그대로 적는다.
- 2026-09-29: 화면의 ISBN 은 작품 페이지 하나에 하나(권별로 나오지 않음). 출판사 엑셀의 ISBN 과 다를 수 있다. 확인 3회.

### 미스터블루 (mrblue.com)
- 2026-09-29: 검색 `https://www.mrblue.com/search?keyword=<제목>` 을 `--links` 로 열면 "만화 … [단행본]" 링크가 작품 주소(`https://www.mrblue.com/comic/<코드>`). 자바스크립트로 그려지므로 render 로 연다.
- 2026-09-29: 서비스가 끝난 작품은 "서비스 종료" 안내만 나온다. 이 경우 날짜를 확인할 수 없다. 같은 작품의 옛 페이지와 새 페이지가 따로 있을 수 있다.
- 2026-09-29: 권 목록의 날짜는 재출간·이관 날짜일 수 있다. 다른 플랫폼의 날짜와 비교한다. 소장가는 하단 "소장 권당 1,000원".

### 네이버시리즈 (series.naver.com)
- 2026-09-29: 검색 `https://series.naver.com/search/search.series?t=all&q=<제목>` 을 `--links` 로 열어 상세 주소(`https://series.naver.com/comic/detail.series?productNo=<번호>`)를 얻는다. WebFetch 는 차단된다. render 로 연다.
- 2026-09-29: 상세 본문에 "글/그림/출판사/이용가"가 있고, 회차 목록은 "N화 (YYYY.MM.DD.)" 형식. 앞부분은 메뉴라 `--find` 로 필요한 줄만 본다.
- 2026-09-29: 단행본 상세에 "재출간 공지"가 있으면 이 플랫폼의 날짜는 최초 공개일이 아니다.
- 2026-09-29: 장르는 "소년" 같은 대분류로 나온다. 소장가가 "쿠키 10개"로만 나오면 원화 환산 근거가 없으니 다른 플랫폼의 가격을 쓴다.

### 카카오페이지 (page.kakao.com)
- 2026-09-29: 검색 `https://page.kakao.com/search/result?keyword=<제목>` 을 render 로 연다. 결과가 없으면 "검색 결과가 없습니다"가 나온다(작품 없음으로 기록). 결과 링크는 `page.kakao.com/content/<번호>`.
- 2026-09-29: 회차 목록 날짜는 "26.07.27" 형식(상세 화면을 `--scroll 10 --find "화|쪽"` 으로 열면 "1화 26.07.2764쪽"처럼 보인다). 이용등급은 검색 결과 화면의 "15세 연령 제한" 같은 표기로 나오고 상세 화면에는 글자로 안 보일 수 있다.

### 교보문고·알라딘·YES24·그 밖
- 2026-09-29: 교보(`search.kyobobook.co.kr/search?keyword=`), 알라딘(`wsearchresult.aspx?SearchWord=`)은 render 로 열린다. 결과가 없으면 다른 단어 기준 결과가 표시되니 같은 작품인지 주의한다.
- 2026-09-29: YES24·북큐브·원스토어·봄툰·교보 eBook 의 검색 주소는 열리지 않았다(메인으로 넘어가거나 오류). 밀리의서재는 로그인이 필요하다. 이런 곳은 "작품 없음"이 아니라 "확인 못 함"으로 적는다.
- 2026-09-29: 국립중앙도서관 서지정보(nl.go.kr/seoji)의 ISBN 검색 주소는 render·WebFetch 로 결과가 나오지 않았다.

## 출판사

### KOCN ((주)코리아컨텐츠네트워크)
- 2026-09-29: 플랫폼 표기는 "KOCN"(리디는 "KOCN 출판"). 소재지는 `http://www.kocn.co.kr/6.htm` 의 "주소 : 서울 광진구 …"(서울). 발행지를 플랫폼·홈페이지에서만 확인했으면 각괄호(`[서울]`). 발행처는 각괄호 없이 `KOCN`(2026-10-01 직원 규칙: 발행처에는 각괄호를 넣지 않는다).
- 2026-09-29: 옛 단행본 만화를 재출간한 자료가 많다. 출판사 엑셀은 최초 연재 플랫폼을 미스터블루로 적지만 리디 등록일(2012년)이 미스터블루·네이버시리즈·카카오페이지(2026년)보다 훨씬 이르다. 리디를 먼저 확인한다. 확인 4회.
- 2026-09-29: 작가 공식 홈페이지 `http://m.hwangzae.com/`(황재, 하단 "Copyright © KOCN Corp.") 메인에 작품별 "업데이트일"이 있다(작품 전체 값). 서비스처 목록에 넣는다. 상세 주소는 render 로 열리지 않았다.
- 2026-09-29: 출판사 엑셀 양식: 머리글이 4행(순번 / 최초 연재 플랫폼 / ISBN/UCI / 제목(도서명) / 권차 / 저자 / 이용대상 / 정가). 제목은 띄어쓰기 없이 적혀 있고, 정가 칸은 비어 있고, 모든 권의 ISBN 이 같다. 출판사·발행일·보상여부 열은 없다. 확인 4회.
- 2026-09-29: 이용등급이 출판사 엑셀(전체이용가)과 플랫폼(15세)이 다른 작품이 있었다.

## 납품 자료(원고)
- 2026-09-29: 옛 단행본 스캔 자료는 표지가 천연색이고 본문이 흑백이다. 이런 자료는 **흑백**이다(2026-10-01 직원 규칙: 표지=천연색, 내용=흑백이면 흑백).
- 2026-09-29: 표지에 권 표시가 원문자(①②)나 '전2권'뿐이고 단위(권·화)가 없는 경우가 있다. 이때 권차는 출판사 엑셀 표기를 따른다.
- 2026-09-29: 표지의 저자 표기가 '作畵'(작화)이고 플랫폼은 '글·그림'일 수 있다. 원고가 우선이다. 엇갈림은 confirm 에 적는다.
- 2026-09-29: 판권면이 없는 납품이 있다. 마지막 쪽이 "끝" 뒤의 빈 쪽일 수 있다. 원고 이미지 수와 플랫폼 쪽수가 1 차이 날 수 있다. issues 에 적는다.

## 도구
- 2026-09-29: render 결과에서 필요한 줄만 보려면 `--find "출판사|이용가|등록일"` 옵션을 쓴다. `| grep` 같은 다른 명령을 잇는 것은 거부될 수 있다.

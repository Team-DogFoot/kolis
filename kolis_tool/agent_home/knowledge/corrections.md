# 직원이 고친 내용 (프로그램이 기록)

반입 전 확인에서 직원이 에이전트의 값을 고치면 여기에 남는다. 같은 출판사·같은 종류의 자료에서 같은 판단을 되풀이하지 않도록 조사 전에 읽는다.

형식: `날짜 | 작품 | 항목 | 에이전트 값 → 직원이 정한 값 | 이유`

1 납품 폴더 → 반입용 엑셀

    
에이전트(클로드)가 출판사 엑셀과 원고를 읽고, 웹에서 조사하고, 칸마다 값을 정해 반입용 엑셀을 만든 뒤 스스로 검사하고 별도 검수까지 받습니다. 끝나면 원고 파일명을 8자리 일련번호로 정리합니다. 보통 10~15분.

값 요약

2 KOLIS 일괄반입 준비 직원 입회 아래에서만

    
Edge 에서 KOLIS 에 로그인해 둔 상태여야 합니다. 프로그램이 그 창에서 납본자료접수 → 일괄반입 → 확인(신규 접수번호 생성) → 비고 → 첨부파일까지 채웁니다. '반입' 버튼은 누르지 않습니다.

    

    

    

    

    

  


  
3 반입 결과 → 원고 폴더명을 콘텐츠ID로

    
가이드 3.4-가. KOLIS 화면에서 "전체출력"을 눌러 내려받은 파일(접수번호 ↔ 콘텐츠ID)로 회차 폴더 이름을 CNTS-… 로 바꿉니다. 원문일괄등록(폴더)은 이 이름을 기준으로 합니다.

    

    
홈 등 다른 화면이어도 납본자료접수로 이동해 접수번호로 찾은 뒤 전체출력합니다. 접수번호를 비우면 지금 화면의 목록을 그대로 출력합니다.

    

    

    

    

    
원문일괄등록(폴더) 직원 입회 아래에서만

    
사람이 할 일: KOLIS 목록 전체 선택 → '원문일괄등록(폴더)' → CNTS 폴더들을 팝업에 끌어다 놓기. 그 뒤 '상태 확인'으로 올라온 폴더를 확인하고, YES 를 넣고 실행하면 전송하기 → 결과표 전체 선택 → 일괄정보입력 → 원문등록까지 단계마다 확인하며 진행합니다.

    

    

  


  
4 썸네일 등록 반복 직원 입회 아래에서만

    
원문일괄등록이 끝난 뒤. KOLIS 납본자료접수에서 접수번호로 찾기 → 전체 선택 → 수정 팝업을 연 상태에서 실행합니다. 지금 열린 건부터 '다음'으로 넘기며 건마다: 비정상 행 삭제·저장 → 열람 행 체크 → 원문등록(썸네일, 유형 검증) → 저장. 예상과 다르면 그 자리에서 멈춥니다.

    

    

    
수정 팝업이 안 열려 있으면 이 번호로 찾기→전체 선택→수정까지 자동

    
0 = 끝까지(편/권차 1에서 자동 종료). 시험용으로만 숫자 지정

복본조사

주무관에게 받은 원부번호 목록을 붙여 넣으면 바로 상태를 읽어 옵니다. 「선택한 원부 처리」를 누르면 원부마다 다음 할 일을 프로그램이 이어서 합니다. 복본 후보가 나온 원부만 멈추고 보여 드리므로, 판정을 보고 그 줄에서 결정하십시오.

자세히

원부번호는 엑셀 한 열을 그대로 붙여 넣어도 되고(줄바꿈), 쉼표·공백·범위(1607-1616)도 됩니다. 붙여 넣으면 원부마다 등록원부관리를 읽어 작품명·건수·상태를 가져옵니다(KOLIS 를 바꾸지 않음). 처리는 원부마다 "복본조사 안 함 → 복본조사(후보가 있으면 프로그램이 등록 자료와 비교해 판정) → 후보 없으면 완료 처리 → 일괄변경(자료유형 1·2, 발행자구분)" 순으로 이어서 하고, 후보가 있는 원부는 완료하지 않고 멈춥니다. 그 원부는 「판정 보기」·「KOLIS 후보 목록」으로 확인한 뒤 「이 원부 완료 처리」로 끝냅니다. 요청으로 처리하며 브라우저를 열지 않습니다. 요청이 안 되면 Edge 화면 방식으로 넘어가고 기록에 남깁니다.

다시 읽기비우기
새 작품출판사가 보낸 폴더를 고르면 A 단계부터 시작합니다. 다른 담당자가 등록한 작품은 B 단계에 원부번호만 넣으면 됩니다.
▶A반입납품 폴더 → 반입용 엑셀 → KOLIS 등록 → 가원부번호
▶1납품 폴더 → 반입용 엑셀

프로그램이 납품 자료를 읽고 웹에서 조사해 반입용 엑셀을 만듭니다. 10~15분 걸립니다.

자세히

출판사 엑셀과 원고를 읽고, 웹에서 조사하고, 칸마다 값을 정해 반입용 엑셀을 만든 뒤 스스로 검사하고 한 번 더 검수합니다. 끝나면 원고 파일 이름을 8자리 일련번호로 바꿉니다.

입력 항목
KOLIS 일괄반입의 비고 칸과 반입용 엑셀 파일 이름에 씁니다. 괄호 안의 차수와 번호를 채우십시오.

▶3-2MODS 구축 · 이용제한

        
먼저 작품 전체를 한 번 판단합니다. 성인물이면 이용제한을 이어서 넣습니다. 그 다음 회차 표에서 한 회차를 고르면 판단 근거가 보이고, 그 회차를 KOLIS 화면에 채워 확인한 뒤 저장합니다.

        
자세히
판단: 회차 전부의 MODS 화면 값을 읽은 뒤 저자전거 연결, 다른이름, 주제명, UCI, 발행처·발행지, 성인물 여부를 근거와 함께 한 번에 정합니다. 여러 작품을 동시에 걸어도 됩니다. KOLIS 는 바꾸지 않습니다. 채우기: 고른 회차의 MODS 수정 화면을 열어 값을 넣습니다(저장 전). 저장: 화면을 확인한 뒤 누릅니다. 되돌릴 수 없습니다.

        

          
사업마다 다릅니다. 모든 회차의 입수처 주기를 이 문장으로 맞춥니다.

          
1 을 거친 작품은 자동으로 들어갑니다. 다른 담당자가 등록한 작품은 받아 둔 원문 폴더를 넣으십시오.

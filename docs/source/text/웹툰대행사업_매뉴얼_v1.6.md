      - 메타데이터와 원문 파일의 정보 일치 여부, 오류사항 확인

        - 검색 결과 중에서 온라인 콘텐츠 결과 확인
        - 대상 자료의 상세보기를 통해 서지사항 및 원문파일 확인해서
납본 자료와 복본인지 확인
      ③ 1, 2번의 방법으로 검색 안 되는 경우 : 국립중앙도서관 홈페이지
검색

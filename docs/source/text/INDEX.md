# 지침 원문 찾아보기 (에이전트용 색인)

도서관이 준 지침 세 가지를 글로 바꾼 것이다. 판단 기준이 헷갈리면 **먼저 여기서 항목 이름으로 Grep** 하고, 걸린 파일의 그 자리를 Read 로 읽는다. 그림 링크(`![…](../images/…)`)는 Read 로 열면 화면 캡처가 보인다(입력 화면 예시는 대개 그림에 있다).

우선순위: 직원 답변(`build-judgment-rules.md`, `corrections.md`) > 웹툰 전용(MODS 입력가이드, 매뉴얼 v1.6) > 공통(정리지침서 2025). 서로 다르면 더 구체적인 웹툰 전용 규칙을 따르고, 엇갈림을 보고한다.

| 파일 | 내용 | 주로 찾는 것 |
|---|---|---|
| `정리지침서_2025.md` | 국립중앙도서관 온라인자료과, 2024-12. 온라인 자료 메타데이터(MODS) 구축 지침. 3장 공통(전자책 기준), 5장 기타 자료에 웹툰(인쇄 쪽 84~86). | 3장 공통 규칙(표제·저자·출처·주제명·식별기호), 5장 웹툰 |
| `웹툰대행사업_매뉴얼_v1.6.md` | 웹툰 납본·수집 대행 사업 매뉴얼 v1.6 (2026-05). 수집·검수·등록·구축·점검 절차와 웹툰 전용 규칙. | 복본조사·유통조사·가격·완결 판단, 구축 절차, 웹툰 규칙 |

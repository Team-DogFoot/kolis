# 웹툰 납본 프로세스 가이드 v1.0 — 그림 판독 기록

- 대상: `docs/source/images/guide/01.png` ~ `38.png` (38장 전부).
- 번호 대응: 파일 번호 = 가이드 "그림 N" 의 N−1 (01.png = 그림 2 … 38.png = 그림 39). 가이드 본문의 "그림 1."(KOLIS 통합검색 결과) 에 해당하는 00.png 는 폴더에 없습니다. 아래에서 01.png 의 내용이 본문의 "그림 1." 설명과 일치하므로, 실제로는 **01.png = 그림 1 … 38.png = 그림 38** 로 보이고, 본문의 "그림 39."(파란색 배경 확인 예시) 가 38.png 안에 함께 들어 있는 것으로 보입니다(추정). 이 기록은 유저가 준 대응(파일 번호 = N−1)을 따르되, 각 항목에 그림 내용이 실제로 어떤 설명문과 맞는지 함께 적었습니다.
- 가이드 설명문은 `docs/source/text/웹툰납본프로세스가이드_v1.0.txt` 의 "그림 N." 줄을 그대로 옮겼습니다.
- 글자는 그림에 보이는 대로 옮기고, 잘려서 끝까지 안 보이는 글자는 `…` 로, 추측은 "(추정)" 으로 표시합니다.
- 그림을 Read 도구로 한 장씩 열어 적었습니다. 03.png(반입용 기초메타데이터)는 원본이 1839×283 로 작아 머리글 행을 4조각으로 잘라 3배 확대해 다시 읽었습니다(확대본은 임시 폴더에만 두었고 저장소에는 넣지 않았습니다).

  1. `/mods/title…`(잘림, 값 열은 비어 있음)
  2. `/mods/titleInfo/title` — 값: 모든 행 "로맨스 낫 로맨틱"
  3. 좁은 빈 열 여러 개(머리글 잘림, 값 없음)
  4. `/moc…` (잘림), `/moc…` (잘림) — 값 없음
  5. `/mods/ti…`(잘림; 권차 `/mods/titleInfo/partNumber` 로 추정) — 값: "01회", "02회", "03회", … "13회" (행마다 1씩 증가)
  6. `/mods/title…`(잘림) — 값 없음
  7. `/r`, `/r`, `/r`, `/r`, `/r`, `/r`, `/r` (좁은 열 7개, 머리글 잘림) — 값 없음
  8. `/mods/nam…`(잘림; `/mods/name[@usage]` 로 추정) — 값: 모든 행 "primary"(빨간 글자)
  9. `/mods/name/namePart` — 값: 모든 행 "김밀가"
  10. `/mods/nan…`(잘림; `/mods/name[@type]` 로 추정) — 값: 모든 행 "개인명"
  11. `/r…`(잘림; `/mods/name/role/roleTerm` 로 추정) — 값: 모든 행 "원작"
  12. `/mods/nan…`(잘림) — 값 없음
  13. `/r`, `/r`, `/r`, `/r`(좁은 열; 그중 하나가 노란 배경 `/r`) — 값 없음
  14. `/mods/name/namePart` — 값: 모든 행 "담장"
  15. `/mods/nan…`(잘림) — 값: 모든 행 "개인명"
  16. `/r…`(잘림) — 값: 모든 행 "각색"
  17. `/mods/nan…`(잘림) — 값 없음
  18. `/r`(노란 배경, 잘림) — 값 없음
  19. `/mods/name/namePart` — 값: 모든 행 "상두"
  20. `/mods/nan…`(잘림) — 값: 모든 행 "개인명"
  21. `/r…`(잘림) — 값: 모든 행 "그림"
  22. `/mods/nan…`(잘림), `/r`, `/r`, `/r`, `/r`, `/r`(좁은 열) — 값 없음

- 값이 들어 있는 열 요약(행마다 같은 값): 표제 "로맨스 낫 로맨틱", 권차 "01회"~"13회", 저자 1 "primary / 김밀가 / 개인명 / 원작", 저자 2 "담장 / 개인명 / 각색", 저자 3 "상두 / 개인명 / 그림", 출처정보 "publication / [서울]".

## 그림 번호 대응에 관한 메모
- 폴더의 38장은 가이드 본문의 "그림 1."~"그림 38."(또는 39) 중 어느 쪽 번호와도 한 칸씩 어긋납니다. 01.png 는 본문 "그림 1."(KOLIS 통합검색) 과 내용이 일치하고, 16.png(썸네일 파일 사이즈 정상 표출 화면) 는 본문 "그림 18." 과 일치하며 "그림 16."(각괄호 안 주소 확인)에 해당하는 그림은 폴더에 없습니다. 즉 **01~15.png = 그림 1~15, 16.png = 그림 18(그림 16·17 중 하나가 빠짐; 17.png = Filezilla = 그림 17), 18.png 부터 = 그림 19 부터**가 내용상 대응입니다(추정). 유저 지시의 "파일 번호 = N−1" 대응은 18.png 이후 구간에서 맞습니다.
- 각 항목 제목은 유저 지시대로 "그림 N = 파일 NN+1" 로 적고, 괄호 안에 실제로 맞는 설명문 번호를 함께 적었습니다.

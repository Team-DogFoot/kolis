유저는 웹 백엔드 + 데브옵스 개발자. FastAPI·도커 컴포즈 기반 운영이 익숙하고 선호함.
프로젝트/기능별로 FastAPI+에이전트를 도커로 말아 운영하는 방식을 원함 ([[typo-inspector-project]]의
5090 리눅스 머신도 이 방식 예정).

**중요한 사업 구조**: 유저는 "개발상회"라는 이름으로 활동하는 공급자(프리랜서/사업자)다.
데이터클립(주)은 그의 **고객사**다. 유저가 견적서를 내고, 5090 워크스테이션을 조립해주고,
오탈자 검수 에이전트 코드를 개발·납품하고 돈을 받는다 (견적 2026-07-08, 총 1,886만원,
소프트웨어 항목 300만원 + 하자보수 3개월). typo_inspector가 바로 그 납품물.
고객사 사용자들은 비개발자 — 결과물은 "브라우저만 열면 되는" 수준까지 포장되어야 함.

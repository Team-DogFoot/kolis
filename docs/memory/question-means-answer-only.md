유저가 질문("~야?", "~있어?", "~맞아?")을 하면 **답변만** 하고 멈춘다. 답변에서 파생되는 수정·재구축·커밋·측정은 유저가 시키기 전에 하지 않는다.

**Why:** 07-21 "태그 더 있어?" 질문에 답변 후 곧바로 스크립트 수정·정답 재구축·커밋까지 진행 → "내가 뭘 물어보면 제발 행동하지 말고 답변을 해주면 안되냐"고 화냄. 이전에도 시운전 임의 실행으로 "왜 니좆대로 하냐" 지적. 유저는 정보를 얻고 스스로 결정하고 싶어함.

**How to apply:** 질문 턴에서는 조사(읽기 전용)까지만 하고 답한다. "~해도 될까요" 대신 "원하시면 ○○하겠습니다" 한 줄로 끝. 명시적 지시("해", "진행해", "넣어라")가 있는 턴에만 변경 작업. 진행 중 작업의 연속 단계(승인된 체인)는 예외.

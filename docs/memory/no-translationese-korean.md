**지시(2026-10-03):** "UI/UX 랑 헤드리스 클로드 번역체 말투 못쓰게 해라." 프로그램 화면 문구, 에이전트가 직원에게 쓰는 글(확인할 것·이유·질문), 그리고 나의 브리핑 모두 해당.

**금지:** "~에 대해/~에 대한", "~것입니다", "~되었습니다", "진행합니다/진행 중", "~하실 수 있습니다", "확인 가능", "수행/제공/존재/포함되어", "~를 기반으로", 영어 낱말(에이전트·프롬프트·로그·필드명). 사용자가 직원 본인이므로 "직원 입회·직원 동의"처럼 제3자 시점의 문구도 금지.

**대신:** 무엇을 했는지 동사로 짧게("다 만들었습니다", "저장했습니다", "하는 중"), 다음 행동을 말하는 상태("다음: 확인 완료 누르기"), 개발 용어는 사용자 말로("설정 파일의 계정" → "KOLIS 자동 로그인(아이디 …)").

**Why:** 사용자는 비개발자 직원. 번역체·개발 용어는 신뢰를 깎고 오해를 만든다. **How to apply:** 화면 문구를 쓰거나 스킬의 출력 형식을 정할 때 이 목록으로 한 번 훑는다. 규칙 원문은 `kolis_tool/agent_home/CLAUDE.md` "글투" 절. 관련: [[kolis-webtoon-project]] [[user-profile]]

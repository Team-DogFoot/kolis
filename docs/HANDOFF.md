- 반입용 양식은 예시 77열 / 완료 사례 83열(5차 실제 승인) / 88열(4차) 이 다르다. 5차는 83열 템플릿 사용.
- 완료 사례 표기: 권차 `1화`(또는 `1`), 발행지 `[서울]`+`ulk`, 이용대상 주기 `전체이용가`/`15세 이용가`/성인용 `19세 미만 구독불가`(공개여부 1), 수집 주기 acquisition, 정가 무료 회차도 유료가, **보상여부는 출판사 '보상안함'이어도 Y·보상금=정가**(관행, 직원 확인 항목).
- 원문일괄등록: 원고 폴더 안에 이미지 외 파일이 있으면 33% 에서 멈춤. 5GB 1시간 반 기준, 실측 2.3GB 33분.
- 되돌리기 기록 파일은 반드시 `_kolis_manifests/` (대상 폴더 밖).
- Somansa DLP: HTTPS 가로챔. 클로드코드는 `NODE_EXTRA_CA_CERTS` 로 해결. Playwright 의 Node 쪽 요청은 CA 키(RSA-1024/SHA-1)가 약해 거부 → 브라우저 페이지 안에서만 요청(검증 끄기 금지).
- `claude -p` 헤드리스는 콘솔 창이 튀어나오지 않게 `CREATE_NO_WINDOW`.
- 작업자 폴더 `C:\Users\User\Desktop\노희원\1.구축\` 에 5차 완료 사례(정답지)와 작업자 도구(ClipToon V8 등)가 있다. 참고만.

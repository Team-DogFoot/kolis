# 화면 설계 판단 (시니어 UI/UX 디자이너 역 서브에이전트, 2026-10-03)

입력: 실제 창 캡처 1장, 사용자 지적 캡처 4장, 상태별 렌더 28장(`work/captures/ui_review/`), `kolis_tool/ui/index.html`, `app.py` 의 `Api`. 전제: 국립중앙도서관 업무 프로그램, 사용자 = 직원 본인. 기준: 행정안전부 전자정부 웹사이트 UI/UX 가이드라인, KRDS, 닐슨 휴리스틱. 아래는 디자이너 결과를 그대로 옮긴 것이다(반영 여부는 유저 결정).

## 0. 전체를 본 소감 — 무엇이 "한 손"을 깨뜨리고 있나

1. **번호 체계가 세 벌.** 카드 머리 `1 / 2 / 3-1 / 3-2`, 카드 안 행 `① ② … ⑦`, 버튼 `5.1 / 5.2`(가이드 그림 번호), 단계 머리 `A / B`. (닐슨 ④, KRDS "하나의 체계로 위계")
2. **상태 표현이 자리마다 다른 말.** 탭 뱃지(색 셋), 단계 머리 `✓ 가원부번호 …`, 카드 머리 `원부번호를 넣으세요 / 3-1 부터 / 다음: YES 입력 후 실행 / 저장 0 · ‼ 넣기만 1 / 준비 중`, 결과 상자 `끝났습니다 / 다 만들었습니다 / 저장했습니다`, 기록 `■ / ✓ / ✗ / ‼ / ===`. (닐슨 ④ ①)
3. **개발 중 보던 것이 그대로 남음.** `/mods/originInfo/dateIssued`, `authors:`, `KSH1998022212`, `확신 low`, `ulk`, `요청 336: POST …`, `환경: ✓ 클로드코드`, `브라우저 조작 부품`, `YES`. (닐슨 ②, 행안부 "이용자가 이해할 수 있는 용어")

빈 기둥·떠 있는 "기록 보기"·1024 아래 절반 빈 것은 한 원인: "숨기기"를 패널 안에 둔 채 패널만 없애서 다시 여는 단추가 갈 곳이 없었다. 단추의 집을 먼저 정해야 했다.

## A. 화면 뼈대

```
┌─ OS 창 제목: KOLIS 납본 도우미 ──────────────────────────────────────────┐
│ 상단 띠 48px   [웹툰 ▾]            KOLIS 계정 홍길동 ✓ │ 진행 기록 ◉ │ 프로그램 상태 │
├──────────────────────────────────────────────┬───────────────────────────┤
│ 작품 탭 줄 40px (고정)                        │ 진행 기록 패널 360px        │
│  [가원부 │ 옆집 기러기 아빠 … ×] [원부 │ 마음휴가 ×] [＋ 작품 추가]      │  진행 기록 · 옆집 …  □ 상세 │
│ 작업 영역 (세로 스크롤, 본문 최대 폭 1040px)    │  20:14:41 ▶ …             │
│  ▾ A 반입 — 납품 폴더 → 가원부번호   [✓ 가원부번호 2026-1687]             │                           │
│     1 납품 폴더 → 반입용 엑셀          [✓ 확인 완료]                      │                           │
│     2 KOLIS 등록                      [✓ 2026-1687]                      │                           │
│  ▸ B 구축 — 원부번호 → 납품          [○ 원부번호 대기]                   │                           │
└──────────────────────────────────────────────┴───────────────────────────┘
```

| 층 | 역할 | 사용자 질문 |
|---|---|---|
| 상단 띠 | 어느 사업(자료 종류), 누구 계정, 프로그램은 멀쩡한가 | 내가 지금 어디 있나 |
| 작품 탭 줄 | 어느 작품, 다른 작품은 어디까지 | 무엇을 다루나 |
| 작업 영역 | 지금 할 일과 한 일 | 다음에 뭘 하나 |
| 진행 기록 | 오래 걸리는 일이 지금 무엇을 하나 | 멈춘 건가 하는 중인가 |

### A-2. 상단 띠 (48px, 고정)
- **`웹툰 ▾`** 맨 왼쪽, 이 화면의 h1(17px 굵게). 누르면 목록(웹툰 / 전자책(준비 중) / …). "자료 종류" 라벨 없음, `aria-label` 만. 32종까지 모양 불변. (질문 6·7, 닐슨 ⑧, KRDS 드롭다운)
- 프로그램 이름 h1 **없앰**(창 제목이 이미 있음). 경로 `웹툰 › 작품명` **없앰**. (닐슨 ⑧ ④)
- **KOLIS 계정 홍길동 ✓**(13px) — 누르면 480px `<dialog>`. 본문 위 인라인 카드 금지. 로그인 전 `KOLIS 계정 없음 !`.
- **진행 기록** 토글 단추 — 패널을 다시 여는 자리는 여기 하나뿐. 작업이 돌고 패널이 닫혀 있으면 파란 점 ◉.
- **프로그램 상태** 단추 — 문제 있으면 `프로그램 상태 ●`. 누르면 대화상자.
- 세 단추 같은 크기(높이 28px, 13px, 테두리 `#c3cad3`), 간격 8px.

### A-3. 작품 탭 줄 (40px, 고정)
- 탭 폭 140~240px, 제목 끝 말줄임. 순서 `[상태 아이콘 16px][단계 뱃지][제목][× 24×24]`, × 는 `flex:none`.
- 단계 뱃지 한 모양(회색 11px): `준비 / 엑셀 / 가원부 / 원부 / 완료`. 색은 상태에만.
- 같은 제목 둘이면 ` · 폴더명` 붙임. 두 줄까지 감쌈.
- **이전 작품** 목록은 "＋ 작품 추가"로 생긴 새 탭 안에만. 상단 드롭다운 없음. 날짜 열 없음. 열: `제목 · 폴더명 | 어디까지 했나 | 폴더 없음 경고`.

### A-4. 작업 영역
- 본문 `max-width:1040px` 왼쪽 정렬(행안부 글줄 40~70자).
- 단계 머리: 캐럿 ▸/▾ 왼쪽, `A` 원(카드 번호와 같은 부품), 제목 `A 반입 — 납품 폴더 → 가원부번호`, `B 구축 — 원부번호 → 납품`, 오른쪽 상태 알약.
- 접힘: 한 번에 단계 하나(가원부 없으면 A, 있으면 B). 단계 안에서는 "지금 할 카드" 하나만 펼치고 끝난 카드는 접되 머리에 결과 알약. 사용자가 바꾼 접힘은 기억.
- 카드 머리 `[번호 원] 제목 … [상태 알약] [▾]`. "접기/펼치기" 글자 없앰.
- 카드 안 `① ②…` 원문자 **없앰**. 라벨만(`납품 폴더`, `작업 번호`, `파일 이름`, `참고 사항`, `실행`).
- "한 단계씩 따로 하기" 묶음은 카드 2 안 맨 아래 접힌 details, 회색 12px `문제가 생겼을 때 한 단계만 다시 하기`. Edge/화면 방식 선택지 제거.
- 되돌릴 수 없는 실행: 체크 상자 + 확인 대화상자(B-2). 빨간 테두리 유지.
- 결과 상자: 상태 아이콘 + 한 문장 + 시각, 테두리 색은 상태 색.

### A-5. 진행 기록 패널
- 폭 `clamp(320px, 28%, 400px)`. 머리 32px: `진행 기록 · 작품명` … `□ 상세 기록` **그뿐**. `지우기`·범례·`숨기기` 제거(여닫기는 상단 띠).
- 숨기면 그리드 열이 0 — 본문은 1040px 를 지키므로 오른쪽이 비는 것은 여백이지 기둥이 아님.
- 1100px 미만: 아래 200px 서랍, 숨기면 서랍 전체가 사라지고 본문이 바닥까지.
- 보통 모드 내용: `▶ 시작 / ✓ 마침 / ✕ 실패 / ! 확인 필요 / 일반 한 줄` 만. 요청/응답 줄은 상세 기록에만.
- 시각 `20:14:41` 한 형식(지금 `오후 8:14:41`·`14시 18분 33초` 둘).

## B. 문구 규칙

1. 합니다체 완결문. 단추는 명사형 동작, 상태 알약은 두세 낱말.
2. 영어는 KOLIS·MODS·UCI·ISBN·KAC·KSH 처럼 매뉴얼에 나오는 고유명·식별자만. `AI, YES, Edge, low, KEY, XML, CNTS, POST` 금지 → `프로그램, (체크 상자), (언급 안 함), 낮음, 복본조사 기준, MODS 원문, 콘텐츠ID, (상세 기록에만)`.
3. 주체는 "프로그램"과 "귀하" 둘뿐. `AI·에이전트·클로드코드·직원이·사람이` 전부 금지.
4. 번역체 금지: `~에 대해, 진행 중, ~되었습니다, ~것입니다, ~에 의해, ~되어야, ~적인`.
5. 내부 식별자·경로·코드값·요청 번호는 상세 기록·툴팁에만.
6. 되돌릴 수 없는 것은 결과를 먼저: "접수번호가 새로 생기고 취소는 주무관에게 요청해야 합니다. 실행하시겠습니까?"
7. 프로그램(에이전트)이 직원에게 쓰는 글도 같은 규칙(스킬 지시문에 넣을 것).

### B-2. 확인 장치 — YES 입력 대체
두 겹: **① 확인 체크 상자**(실행 단추 왼쪽, 글자가 서약문: `☐ 반입용 엑셀의 확인 항목을 모두 보았습니다`) → 체크해야 단추 활성. **② 확인 대화상자**(480px): 제목 `KOLIS 등록을 실행합니다`, 본문에 무엇이 일어나는지, 단추 `[취소] [KOLIS 등록 실행]`(동작 이름). 3-1 은 `미리 보기`와 `실행` 두 단추로 분리(입력에 따라 글자가 바뀌는 단추 금지). (닐슨 ⑤, KRDS 모달·체크박스, 행안부 "중요 행위 전 명확한 확인")

### B-3. 교정표 (요약 — 전문은 디자이너 결과 원문)
- 상단: `KOLIS 자동 로그인` → `KOLIS 계정 홍길동 ✓`; `KOLIS 로그인 필요` → `KOLIS 계정 없음 !`; `다른 계정으로` → 계정 글자 자체가 단추, 대화상자 `KOLIS 계정 바꾸기`; `계정 지우기` → `이 계정 쓰지 않기`; 프로그램 상태의 `✓ 클로드코드 · ✓ Edge · 브라우저 조작 부품` → `조사 도구 ✓ · 조사 도구 로그인 ✓ · 브라우저 ✓`; KOLIS 창/팝업/파일 창 줄 삭제 → `KOLIS 연결: 정상`; `기록 파일: C:\…` → `기록 파일 열기`.
- 탭·새 작품: 뱃지 한 모양 `준비/엑셀/가원부/원부/완료`; `전에 하던 작품 (누르면 엽니다)` → `이전 작품`; `반입용 엑셀 있음 · 확인 전` → `반입용 엑셀 확인 전`; `시작만 함` → `폴더만 고름`; `폴더가 지금 없음` → `폴더를 찾을 수 없음`.
- 단계 머리: `A 반입 — 납품 폴더 → 가원부번호 (반입용 엑셀 → KOLIS 등록)`, `B 구축 — 원부번호 → 납품 (복본조사 → 일괄변경 → MODS 구축 → 점검)`; `원부번호를 받으면 시작` → `○ 원부번호 대기`; `원부 1607 · 저장 0 · ‼ 1` → `원부 1607 · 저장 0/1 · ! 확인 1`.
- 카드 1: `AI 가 …` → `프로그램이 납품 자료를 읽고 웹에서 조사해 반입용 엑셀을 만듭니다. 10~15분 걸립니다.`; `넣은 값 보기 (…)` → `입력 항목`; 라벨 `납품 폴더 / 작업 번호 / 파일 이름 / 참고 사항 / 실행`; 실행 단추 `반입용 엑셀 만들기 / 다시 만들기`; 결과 `반입용 엑셀을 만들었습니다. 아래 확인 항목과 엑셀을 보십시오.`; `11행 · 사람이 확인할 칸 68개 · 13분 걸림 · 원고 파일명 149장 정리` → `11건 · 확인할 칸 68개 · 13분 · 원고 파일 이름 149장 정리`; **`/mods/originInfo/dateIssued (발행일) · 전체 11행` → `발행일 · 전체 11건`**(경로는 툴팁), `/mods/identifier` → `식별기호(ISBN)`, `reward_yn` → `보상 여부`, `compensation` → `보상금`; 표 열 `넣은 값 / 출판사 값 / 확인이 필요한 이유 / 근거 / 결정이 필요합니다`; `확인 완료 — 노란색·메모 지우기` → `확인을 마쳤습니다 — 표시를 지우고 다음 단계로`(대화상자 `[취소] [표시 지우기]`); `설정 — 모든 작품에 똑같이 알려 줄 것` → `공통 지시 사항`.
- 카드 2: `KOLIS 등록 — 반입 → 가원부번호`; 실행 행 `☐ 반입용 엑셀의 확인 항목을 모두 보았습니다 [KOLIS 등록 실행]`; 비활성 사유 `1 을 먼저 하십시오 / 1 의 결과에서 「확인을 마쳤습니다」를 먼저 누르십시오 / 위 상자에 체크하십시오 / 실행할 수 있습니다`; 완료 `✓ KOLIS 등록을 마쳤습니다 — 접수번호 991 · 가원부번호 2026-1687 · 11건 · 2분 52초 · 검사 165개 통과 · [가원부 파일 열기]`; `썸네일이 동봉되지 않음(등록하지 않음)` → `썸네일이 없어 건너뜀`.

| 상태 | 아이콘 | 색 | 낱말 | 탭 | 단계/카드 알약 | 결과 상자 | 기록 줄 |
|---|---|---|---|---|---|---|---|
